# اعتبارسنجی این تغییر

## نتایج محلی

- Python 3.13: **۵۰ آزمون موفق** (`pytest -q`) شامل ۲۳ آزمون قبلی و ۲۷ آزمون جدید.
- افزونه PyMuPDF نصب و استخراج PDF متنی/رد PDF فاقد متن آزموده شد.
- `python -m compileall -q rasad`: موفق.
- بررسی syntax تمامی فایل‌های `web/js/*.js` با Node 24: موفق.
- `git diff --check`: بدون خطای whitespace.
- آزمون مرورگر محلی Chromium، viewport دسکتاپ ۱۴۴۰×۱۰۸۰ و موبایل ۳۹۰×۸۴۴: ورود متن خصوصی، انتخاب خودکار سند، ثبت تحلیل پرسش بی‌ربط، نمایش gap، ثبت یادداشت و تأیید انسانی، انتشار درون‌سامانه؛ بدون خطای JavaScript. عرض سند موبایل ۳۹۰ و بدون overflow افقی مشاهده شد.
- یک آزمون integration، worker و دروازه LLM را از مسیر HTTP واقعی **به سرور شبیه‌ساز محلی** همراه JSON Schema، ثبت توکن و provenance آزمود. این یک مدل زبانی واقعی نیست.
- CI برای Python 3.11 و 3.13 اضافه شده؛ قبولی اجرای remote CI و Python 3.11 در این گزارش ادعا نمی‌شود.
- یک هشدار deprecation از سازگاری Starlette TestClient/httpx باقی است؛ اجرای آزمون‌ها را ناموفق نکرده است.

## آنچه تأیید نشده است

هیچ کلید واقعی فراهم‌کننده استفاده نشده، آزمون پولی انجام نشده و برنامه در محیط عملیاتی مستقر نشده است. کیفیت فارسی/عربی/انگلیسی مدل واقعی، هم‌معنایی ادعا/شاهد، دقت داور، embedding چندزبانه، OCR بینایی و endpoint صوت با حساب واقعی هنوز باید مطابق `evaluation-plan.md` ارزیابی شود. تست شبیه‌سازی‌شده را نباید benchmark دقت یا تضمین صحت معرفی کرد.

## فاز دوم: گردش بازبینی و شواهد بیرونی

- Python 3.13: **۷۹ آزمون موفق**؛ ۵۰ آزمون پایه و ۲۹ آزمون گردش/امنیت افزوده‌شده، با مدل و دریافت بیرونی شبیه‌سازی‌شده.
- پوشش جدید: ابطال تأیید هنگام ویرایش، نسخه منتشرشده ثابت، کنترل نسخه کهنه، شاهد نامجاز، جدایی مجوز خواندن بازبین از ویرایش/انتشار/حذف، لغو ارجاع، سیاست منع خودتأییدی، روابط خصوصی و چرخه، الزام سند تازه و دامنه آماده تحلیل اولیه، cache مرحله، ثبت مصرف قبل از لغو، عدم cache پاسخ نامعتبر، بازیابی lease منقضی و داور ردکننده تغییر عدد.
- ورودی بیرونی: رد scheme/port/credentials/control character، DNS داخلی/رزروشده، redirect خارج از allowlist، robots، hash فایل، اتصال به IP معتبر با TLS SNI و رد compression/اندازه نامجاز پیش از خواندن body. همه موارد با شبیه‌ساز؛ نه ادعای ممیزی مستقل امنیت یا آزمون شبکه عمومی.
- آزمون مرورگر Chromium محلی در دسکتاپ ۱۴۴۰×۱۰۸۰ و موبایل ۳۹۰×۸۴۴: سند خصوصی، ساخت draft، اصلاح به نسخه ۲، بسته‌بودن تأیید پیش از بازاعتبارسنجی، بازاعتبارسنجی، نمایش تاریخچه نسخه ۱، تأیید و انتشار نسخه ۲؛ بدون خطای JavaScript و overflow افقی موبایل.
- آزمون UI فوق روی مسیر gap بدون API پولی انجام شده است. این نتیجه اثبات توان داور مدل یا کیفیت خبر واقعی نیست.
